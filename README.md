# WordPress Website Launch Checklist

A practical checklist for developers and business owners preparing to launch a WordPress website.

Use the sections relevant to your project. Hosting features and plugin settings vary, so confirm how each item works on your setup.

## Content and navigation

- [ ] Replace placeholder text and demo images.
- [ ] Review service descriptions, prices and contact details.
- [ ] Check the main menu, footer links and important buttons.
- [ ] Confirm permission to use photos and testimonials.
- [ ] Check that error pages help visitors find useful content.

## Mobile and accessibility

- [ ] Review key pages on a real phone.
- [ ] Check menus, forms and buttons on smaller screens.
- [ ] Test keyboard navigation and visible focus indicators.
- [ ] Add descriptive alternative text to informative images.
- [ ] Check readable text sizes and colour contrast.

## Forms and enquiries

- [ ] Submit a test enquiry and confirm delivery.
- [ ] Check validation and success messages.
- [ ] Verify phone, email and WhatsApp destinations.
- [ ] Confirm spam protection works.
- [ ] Avoid collecting information the business does not need.

## Search and redirects

- [ ] Review page titles and main headings.
- [ ] Check canonical URLs and XML sitemap availability.
- [ ] Confirm public pages are not accidentally blocked from indexing.
- [ ] For redesigns, map changed URLs to relevant replacements.
- [ ] Test redirects and check for broken internal links.

## Performance and security

- [ ] Resize and compress unnecessarily large images.
- [ ] Test caching without breaking forms or checkout.
- [ ] Confirm HTTPS works across the website.
- [ ] Update supported themes and plugins.
- [ ] Remove unused plugins and unnecessary user accounts.
- [ ] Create a backup and confirm the restoration process.

## Ownership and handover

- [ ] Confirm business control of the domain and hosting.
- [ ] Provide individual accounts with appropriate permissions.
- [ ] Document paid services, renewal dates and responsibilities.
- [ ] Explain how to edit essential content.
- [ ] Agree who handles updates, backups and support after launch.

## Contributing

Suggest improvements with a clear explanation. Do not include passwords, customer information or private website data in issues or examples.
